# NOVI — User Experience Architecture & Interaction Principles (`UX.md`)

---

## 1. Core UX Philosophy: Calm & Progressive Clarity

NOVI is designed to be **simple on first glance, powerful when explored**. 

Users should never be forced to process a mountain of dashboards, complex telemetry charts, or high-pressure counters the moment they open the application.

### Key Tenets
1. **Content > Function > Decoration**: Visual elements exist solely to facilitate understanding and action.
2. **Progressive Disclosure**: Surface the most important context immediately; reveal deep logs, timetable configurations, and diagnostics only when requested.
3. **Respectful of Time**: Zero tedious manual logging. NOVI quietly works in the background and surfaces meaningful daily rhythm insights.
4. **Forgiving & Adaptive**: Life rarely goes exactly to plan. When a session starts early or runs late, NOVI smoothly adapts rather than flagging failures.

## 2. Information Architecture & Navigation

### Current Deficiencies of Old Navigation (LogMyLife)
- The legacy app crammed **7 tabs** into a mobile bottom navigation bar (`Overview`, `Planner`, `Timeline`, `Focus`, `Habits`, `Stats`, `Settings`).
- On standard mobile displays, 7 tabs result in severe horizontal crowding, truncated labels, cramped touch targets, and visual exhaustion.

### The NOVI Navigation Model (Clean 4-Area Architecture)
NOVI streamlines navigation into **4 core primary destinations** with high semantic clarity and contextual accessibility, strictly complying with Material 3 navigation ergonomics (3 to 5 destinations max):

```
┌────────────────────────────────────────────────────────────────────────┐
│                        NOVI Application Shell                          │
├────────────────────────────────────────────────────────────────────────┤
│  Top App Bar: Greeting / Section Title + Profile/Settings Quick-Avatar │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│  [ Tab 1: Today ]      [ Tab 2: Schedule ]     [ Tab 3: Focus ]        │
│  • Current Focus Card  • Day Timetable / List  • Deep Focus Timer      │
│  • Up Next Activity    • Reality Timeline Flow • Soundscapes           │
│  • Daily Reflection    • Auto-Shift Controller • Completed Blocks     │
│  • Quick Actions       • Quick Activity Add                            │
│                                                                        │
│  [ Tab 4: Rhythm & Insights ]                                          │
│  • Consistency Matrix (7-day calm check-in)                            │
│  • Long-Term Goals & Syllabus Progression                              │
│  • Meaningful Focus Telemetry (without XP hype)                        │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│  Floating Live Focus Pill (Active countdown & controls across tabs)    │
├────────────────────────────────────────────────────────────────────────┤
│  Material 3 Bottom Navigation Bar (4 Destinations)                     │
│  [ Today ]       [ Schedule ]       [ Focus ]       [ Rhythms ]        │
└────────────────────────────────────────────────────────────────────────┘
```

> **Settings & System Preferences**: Seamlessly accessible via the top-right profile avatar on the Today screen and through a dedicated section in Rhythm/Insights, keeping primary navigation distraction-free.

## 3. Screen Hierarchy & Content Structure

### A. "Today" Screen (Home / Root Experience)
The Today screen directly answers three essential questions within 3 seconds:
1. **Where am I?** — Date, greeting, and high-level daily progress.
2. **What matters right now?** — The active or upcoming scheduled block with start countdown.
3. **What can I do next?** — Quick actions ("Start Focus", "Plan New Block", "Check Off Routine").

**Structure**:
- **Header**: Quiet greeting (`"Good morning, Alex"`), date, profile/settings avatar.
- **Current / Next Focus Hero**: Clean M3 card with the current activity, start time, category accent, and "Start Focus" button.
- **Daily Rhythm At a Glance**: Calm dual-tone progress ring indicating hours focused vs today's target (e.g. `3.5 / 6h`).
- **Today's Schedule Highlights**: Clean 3-item preview of upcoming plans with "See all" linking to Schedule.
- **Daily Reflection & Ambient Note**: Brief, supportive summary generated by on-device insights (e.g., *"Morning deep work completed smoothly. 2 focus blocks remaining."*).

### B. "Schedule" Screen (Intent & Reality Flow)
Unifies the day planner and reality timeline into a single, cohesive view:
- **Header & Date Navigator**: Clean day switcher (`< Today >`), jump-to-date picker.
- **View Mode Switcher**: Material 3 Segmented Button (`Timetable` vs `Reality Timeline`).
  - *Timetable*: Visual hourly grid with color-coded activity blocks and auto-shift notices.
  - *Timeline*: Reality view comparing planned blocks with detected on-device application evidence.
- **Floating Action**: Clean M3 FAB to schedule an activity.

### C. "Focus" Screen (Distraction-Free Interval Space)
- **Interval Selector**: M3 tonal chips (`15 min`, `25 min`, `45 min`, `60 min`).
- **Timer Display**: Large, calm countdown clock framed by an M3 circular progress track.
- **Ambient Soundscapes**: Subtle chip picker (`Rain`, `Forest`, `White Noise`, `Off`).
- **Controls**: Large filled primary button (`Start Focus` / `Pause` / `Finish`).
- **Foreground Bridge**: Syncs with Android Foreground Service for persistent notification controls.

### D. "Rhythm & Insights" Screen (Habits & Long-Term Mastery)
- **Daily Consistency Matrix**: 7-day row of quiet circular check-ins for core routines (e.g., Reading, Workout, Code). No aggressive streak loss penalties.
- **Goals & Syllabus Progress**: Smooth M3 progress tracks for active courses or project targets.
- **Focus Patterns**: Mindful weekly focus distribution (by category) and context switch averages.

## 4. State Design: Empty, Loading, and Error States

### A. Empty States
Empty states in NOVI are calm, positive, and action-oriented.
- **Rule**: Never show a blank screen or a dead-end message like *"No data available"*.
- **Pattern**:
  - *Icon*: 32dp soft vector icon in `surfaceContainerHigh`.
  - *Heading*: Calm title (`"Nothing planned for today"`).
  - *Description*: Helpful subtitle (`"Enjoy your open time, or schedule a focus block to get started."`).
  - *Action*: Tonal M3 button (`"Plan an activity"`).

### B. Loading States
- **Inline over Full-Screen**: Use subtle skeletons and integrated progress indicators rather than blocking modal overlays.
- **Smooth Content Reveal**: Staggered fade-in on initial data arrival.

### C. Error & Recovery States
- **Human Tone**: Explain what happened simply (`"Couldn't load your schedule right now."`).
- **Actionable**: Always provide an immediate recovery path (`"Try again"`).

## 5. Interaction Patterns & Micro-Affordances

1. **Auto-Shift with Graceful Undo**: When an activity starts late or early, an M3 notification banner (`NoviBanner`) slides into view with a 1-tap `"Undo"` action.
2. **Persistent Live Focus Pill**: When a focus session is active, a floating pill appears above the bottom navigation bar across all tabs, showing the ticking countdown and quick pause/stop controls.
3. **Reconciliation Inspection**: Tapping any occurrence opens a clean 28dp M3 bottom sheet displaying matched app usage evidence, duration breakdown, and interruption logs.
4. **Tactile Haptic Feedback**: Subtle haptic taps on timer completion, habit check-off, and schedule adjustments.
